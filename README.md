# Relay — удалённый рабочий стол

Relay — настольный клиент для Windows с интерфейсом на русском языке. Профили хранятся локально, а сеансы открываются в отдельном окне встроенного клиента Windows (`mstsc.exe`). Windows отвечает за отрисовку, ввод, аутентификацию, сжатие и каналы перенаправления. Relay не собирает пароли.

## Запуск

Готовый файл после сборки находится в `bin\Release\net48\RelayRdp.exe`. Для запуска нужны Windows 10 или 11, .NET Framework 4.8 либо новее и встроенный клиент «Подключение к удалённому рабочему столу». Для сборки нужен .NET SDK с поддержкой WPF и пакет разработчика .NET Framework 4.8.

```powershell
dotnet build .\RelayRdp.csproj -c Release
.\bin\Release\net48\RelayRdp.exe
```

## Подключение

1. На удалённом компьютере откройте **Параметры → Система → Удалённый рабочий стол**. Включите подключение и добавьте нужных пользователей. Хостом может быть Windows Pro, Enterprise, Education или Windows Server. Windows Home может выступать клиентом.
2. Откройте Relay и введите имя или IP-адрес компьютера. Для нестандартного порта используйте `host:port` или `[IPv6]:port`. Поле шлюза предназначено для RD Gateway вашей сети.
3. Выберите параметры на вкладках **Экран** и **Файлы и устройства**. Нажмите **Подключиться**. Вход и состояние сеанса показывает клиент Windows. **Сохранить** добавит профиль в боковую панель.

Физический монитор на хосте не требуется. Windows создаёт удалённый рабочий стол RDP, пока хост включён, доступен по сети и принимает подключения. На клиентских выпусках Windows подключение по RDP может блокировать локальный экран. RDP-сеанс не транслирует экран входа BIOS/UEFI.

После обновления безопасности Windows за апрель 2026 года клиент может отключать запрошенные ресурсы до явного подтверждения. Если в диалоге подключения перечислены буфер обмена, диски или устройства, поставьте галочки напротив нужных ресурсов. [Диалоги безопасности .rdp](https://learn.microsoft.com/en-us/windows-server/remote/remote-desktop-services/remotepc/understanding-security-warnings)

## Файлы и устройства

- **Буфер обмена** включён в новом профиле. Текст, изображения и файлы можно копировать в обе стороны в пределах политик Windows. Для больших файлов используйте перенаправленные диски.
- **Диски и флешки** доступны в удалённом Проводнике в разделе **Этот компьютер** и по пути `\\tsclient\D`, если перенаправлен диск `D:`. Можно задать буквы дисков, выбрать все или подключённые после входа.
- **USB** использует штатное перенаправление RDP для совместимых устройств. Доступ зависит от политик клиента и хоста, версии Windows и драйверов. Для выбора конкретных USB-устройств откройте **Действия → Экспортировать и открыть настройки Windows**. Затем откройте **Локальные ресурсы → Подробнее**. Поддерживаемые USB-устройства видны там, когда соответствующая политика разрешена. Сохранённый там файл можно запустить через **Открыть файл .rdp**.
- **Периферия** настраивается отдельно. Доступны звук, микрофон, камеры, принтеры, смарт-карты, COM-порты, устройства MTP/PTP и ключи WebAuthn в рамках возможностей установленного RDP-клиента и хоста.

Профили хранятся в `%LOCALAPPDATA%\RelayRdp\profiles.json`. Опция **Экспортировать .rdp** сохраняет настройки сеанса для встроенного клиента Windows. `Ctrl+S` сохраняет профиль, `Ctrl+N` открывает новый.
